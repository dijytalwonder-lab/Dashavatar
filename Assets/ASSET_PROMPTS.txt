================================================================================
 DASHAVATARA — WORLD 1: MATSYA (The Great Flood)
 ART ASSET PROMPTS  —  CHIBI CUTE STYLE
================================================================================

STYLE: All assets are CHIBI CUTE — big heads, tiny bodies, oversized sparkly
eyes, soft rounded shapes, chubby proportions, gentle pastel-on-deep-blue
palette, thick clean outlines, soft cel shading, adorable and friendly (even the
demon is a "cute-scary" chibi). Mobile game sprite art. Think "kawaii mythology."

The game currently runs on PROCEDURAL placeholder art (drawn in code, no image
files). To use these instead:
  1. Generate each image below as a transparent PNG.
  2. Save it as   public/images/<key>.png   (key is in [brackets]).
  3. In src/scenes/PreloadScene.js -> preload(), load it, e.g.
        this.load.image('matsya', 'images/matsya.png');
  4. Delete the matching block in src/systems/Textures.js so the real art wins.
Runtime keys must stay EXACTLY as listed. Keep the same facing direction.

GLOBAL RULES FOR EVERY PROMPT
- 2D chibi sprite, front-or-side as noted, centered, transparent background.
- Thick rounded outlines, soft shading, big cute eyes, no text, no watermark.
- Consistent top light, subtle cyan/gold rim light.
- Palette anchors: deep teal water (#041627→#146c94), sacred gold (#ffd257),
  Matsya teal (#3fc1c9), demon purple (#8a2be2), pastel accents.
- No baked drop shadow (the engine adds glow/shadows).
